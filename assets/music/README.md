# Музыкальные подложки

Положи сюда mp3 и укажи `MUSIC_DIR=assets/music` — на каждый ролик берётся
случайный трек. Либо задай конкретный файл через `MUSIC_PATH`.

Треков в репозитории нет намеренно: музыка лицензируется, и её нельзя
раздавать вместе с кодом. Источники без роялти: Pixabay Music, Uppbeat,
Epidemic Sound (по подписке), YouTube Audio Library.

ВАЖНО про «трендовые» звуки: трек, вшитый в файл, TikTok не считает своим
звуком. Алгоритмические бонусы за популярный аудиотрек даёт только звук,
выбранный в самом редакторе при загрузке. Поэтому рабочая схема такая:
подложка в файле — нейтральная и тихая (или её нет вовсе), а трендовый звук
накладывается уже в приложении поверх.
